# Mossheart

A cozy botanic roguelike tower defence in a voxel bell jar.

**Play:** https://alexhudelot.github.io/mossheart/

It runs in Chrome or Edge with WebGPU, on a computer or on Android 12+ (Chrome 121+), and in Safari 26+.
Some phone GPUs (Samsung Xclipse, for one) are blocklisted in Chrome: turn on
`chrome://flags/#enable-unsafe-webgpu`, tap Relaunch, and reload.

Controls: drag to pan, wheel to zoom, Q/E to turn, 1–4 to pick a seed, space to start a wave.

`index.html` is the one-file build of the game (`games/Mossheart/tools/artifact.ps1`). The source lives in a
private repository; this one only hosts the build.
